# 🧠 Desafio HTML Básico

Projeto desenvolvido como parte de um desafio de aprendizagem em **HTML**, com foco na utilização das principais tags e na estruturação correta de um website simples.

---

## 📌 Objetivo

- Praticar a estrutura básica do HTML
- Utilizar corretamente tags semânticas
- Criar navegação interna com âncoras
- Organizar o conteúdo de forma clara e acessível

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- Visual Studio Code
- Git e GitHub

---

## 📚 Tags HTML Utilizadas

- `h1` até `h6`
- `p`, `strong`, `i`, `u`, `mark`, `small`, `del`
- `ul`, `ol`, `li`
- `a`
- `hr`
- `sub`, `sup`
- `blockquote`
- `abbr`
- `font` (tag legada)

---

## 🧭 Navegação

O site possui um menu com navegação por âncoras, permitindo acesso rápido às seções da página.
